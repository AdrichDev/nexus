# assets/

Imágenes del producto que no sirve la aplicación: de momento `logo.png`, el
logotipo original a tamaño completo del que salen el resto de piezas gráficas.

**No confundir con `frontend/logo.png`**: ese es un archivo DISTINTO, es el que
el HUD pide como `/static/logo.png` y por eso tiene que seguir viviendo dentro de
`frontend/`. Mover el de aquí no afecta a la interfaz.
