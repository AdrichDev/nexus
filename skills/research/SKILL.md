# Skill: Investigación / Informes

Investiga en la web y redacta informes completos con fuentes.

- "investiga <tema> y hazme un informe" → busca en la web (DuckDuckGo),
  lee las mejores fuentes, y redacta un informe estructurado que se guarda
  en `data/reports/` y se abre en el navegador.
- "tendencias de <nicho>" → informe de tendencias del tema.
- "informe económico" / "dónde puedo apurar gastos" → analiza las facturas
  y datos económicos en memoria y sugiere dónde recortar y dónde invertir.

Nota honesta sobre Instagram/TikTok: no tienen API pública gratuita de
tendencias y bloquean el scraping directo. nexus investiga con fuentes
web abiertas (blogs, informes, noticias del nicho); para datos nativos de
Instagram conéctalo vía n8n a la API oficial de Meta o a un proveedor
(Apify, Brightdata) — la arquitectura ya lo permite.
