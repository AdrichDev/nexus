ASISTENTE DE INSTALACIÓN — se hace UNA vez y queda todo configurado

BIENVENIDO

Vamos a dejar tu sistema listo en unos pocos pasos: tu nombre, su personalidad, los permisos que le das sobre este equipo, dónde guarda su memoria, y las cuentas e IAs que quieras conectar. Todo se puede cambiar después en ⚙.

Instalación limpia: el sistema arranca SIN memoria — solo con sus nodos de conocimiento predefinidos. La memoria la iréis construyendo vosotros.

2 · PERSONALIDAD DEL BOT

Elige cómo quieres que sea tu asistente. No es cosmético: cada personalidad cambia de verdad su forma de hablar y de tratarte (se inyecta en el cerebro del modelo).

3 · PERMISOS SOBRE ESTE EQUIPO

Igual que un sandbox: tú decides hasta dónde llega tu sistema. Se puede cambiar en cualquier momento desde ⚙ → Permisos.
Leer el hardware — CPU, RAM, placa base, discos, GPU y temperaturas. Alimenta el panel «Recursos» y «Estado del equipo». Sin esto, tu sistema no verá nada de tu máquina.
🔒 Sandbox

Solo puede leer y escribir en SU carpeta (data/sandbox dentro de la instalación). Lo más restrictivo: no toca nada tuyo.

📁 Carpetas concretas

Solo las carpetas que tú apuntes abajo (una por línea). Ideal para darle Documentos o un proyecto y nada más.

💻 Todo el equipo

Acceso completo, como un usuario más: crear documentos en el escritorio, explorar discos, mover archivos…

4 · MEMORIA / BASE DE DATOS

¿Dónde guarda tu sistema su memoria a largo plazo?
📄 Local (en la instalación)

La memoria se crea dentro de la carpeta de instalación (data/): notas y grafo en archivos. Cero requisitos, funciona ya. Búsqueda por palabras (sin búsqueda semántica).

🐳 Docker (recomendado)

Postgres + pgvector en un contenedor: memoria SEMÁNTICA real (encuentra por significado) + n8n para automatizaciones. Necesita Docker Desktop; si no lo tienes, abajo tienes el enlace.

🌐 Servidor externo

Ya tienes un Postgres (NAS, VPS, otro PC): pon su URL de conexión y tu sistema guardará la memoria allí.

Comprobando Docker…
¿No tienes Docker? Descárgalo aquí: docker.com/products/docker-desktop — instálalo, ábrelo una vez y vuelve a este paso.

5 · GOOGLE (CALENDAR + GMAIL) — opcional

Para que tu sistema lea tu correo y tu calendario necesita unas credenciales OAuth de Google (gratis, ~5 minutos). Si no lo quieres ahora, salta este paso.
  1. Entra en console.cloud.google.com y crea un proyecto (p.ej. «nexus»).
  2. Menú → APIs y servicios → Biblioteca: activa Gmail API, Google Calendar API y Tasks API.
  3. Pantalla de consentimiento OAuth → tipo Externo → añade tu email como usuario de prueba.
  4. Credenciales → Crear credenciales → ID de cliente de OAuth → tipo Aplicación de escritorio.
  5. Copia el ID de cliente y el Secreto aquí abajo.
  6. Al terminar, dile a tu sistema «lee mis correos»: se abrirá el navegador para autorizar (una sola vez).

6 · CEREBRO (IA)

nexus puede pensar con IAs de pago (token) o con modelos LOCALES gratis (Ollama / LM Studio). Puedes poner varios y cambiar en ⚙ cuando quieras.
Con qué modelo indexa y recuerda nexus tu conocimiento. «Automático» usa el mismo cerebro que elijas arriba. El almacén será tu base de datos (Docker) si la montas, o un archivo local si no — en ambos casos funciona.
