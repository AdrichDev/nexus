- `skills/google_workspace/skill.py` `_email_actions_job` already reads unread mail, classifies with the LLM and creates
  tasks via `_create_everywhere` (Google Calendar/Tasks + board `tag="correo"`). Gaps: notes not stored on the board,
  no email id (rerun duplicates), only alta/media, classification output has no type/urgency fields.
- Open defect: Tareas view is stale after chat/voice-created or restored tasks (probe FINDING, a24bf10).
